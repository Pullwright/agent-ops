# Scripts and entry points reference

An index of every script under `lib/` and `scripts/`, grouped by directory,
each row the first paragraph of that script's own header comment. Generated
by `scripts/render-scripts-index.sh`; edit a script's own header comment to
change its row here, never this file directly.

`lib/` carries no index of its own beyond this one: its files are sourced,
never executed, so there is no `--help` to read instead. `scripts/doctor.sh`
and the repository's own `AGENTS.md` are still the place to start for what
to run and when; this page is for finding a script once you already know
roughly what it should do.
