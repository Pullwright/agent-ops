# Contributing

This repository is worked by both a human maintainer and an autonomous agent fleet, and both follow the same conventions.

**Start here:** `docs/guides/contributing/README.md` is the comprehensive contributor guide covering the development loop, the as-built specifications, documentation workflow, and what every pull request must carry.

**For the full ruleset** — branch conventions, commit message format, tech-debt filing, generated regions — see `AGENTS.md` (which `CLAUDE.md` imports). It is written for agents but every rule applies equally to humans.

**For an overview of all documentation** and how to find answers to common questions, see `docs/README.md`.
